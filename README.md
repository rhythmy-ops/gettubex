# GetTube

GetTube 是一个轻量、本地优先的桌面媒体下载工具，面向 YouTube、哔哩哔哩、抖音和 X。

> **免责声明**：本项目仅供个人学习与研究使用。请遵守目标平台的服务条款及所在地区法律法规，仅下载您有权保存的内容，不得将下载的内容用于商业用途或再分发。本项目不绕过任何数字版权保护（DRM）。

## 当前状态

v0.4.0（v4）。目前包含：

- Tauri + React 桌面界面
- 严格的平台链接识别
- yt-dlp 媒体信息读取和下载命令层
- FFmpeg 合并参数
- 全局及 YouTube/X 单独代理策略
- 本地设置持久化
- SQLite 任务与历史持久化
- 实时下载进度、取消和失败重试
- 四个平台的 Cookie 文件与本地托管粘贴导入
- 稳定任务 ID，为后续 OpenClaw 接口预留
- 抖音无水印播放地址解析，失败时不回退带水印版本
- X/Twitter 与受控 `t.co` 短链接解析
- GitHub Release 版本检查、提示和发布页跳转（不自动安装）
- 播放列表 / B 站合集与收藏夹 / 多 P 列表预览，勾选、区间与批量下载（YouTube + B站）
- UP 主近期作品枚举与选择下载（频道 / 空间，30/50/100 条可调）
- 真排队调度：并发满时任务排队等待而不是报错，重启后排队任务自动继续
- 批量任务按批次聚合展示、整批取消、自动整理到列表名子文件夹
- 字幕下载开关（YouTube/B站，中英）、B 站弹幕下载（danmaku.xml，默认开）
- 仅音频格式选择：MP3 / M4A / OPUS（YouTube/B站）
- 列表条目"已下载"去重提示（不阻断重复下载）
- 元数据与封面嵌入（默认开；M4A/MP4 完整封面支持需另行安装 AtomicParsley，未装自动降级仅元数据）
- 下载归档：批量下载自动跳过已下过的视频（单视频手动下载永不跳过；被跳过的条目标注"已跳过（归档）"）
- yt-dlp 引擎状态：版本、实际路径、新版检查与升级命令提示（GUI 启动时自动在 homebrew 等常见位置定位引擎）

抖音图集、文件选择器、OpenClaw 接口和自动更新仍在后续里程碑中。

## 开发环境

需要 Node.js、Rust、yt-dlp 和 FFmpeg（M4A/MP4 封面嵌入可选装 AtomicParsley）：

```bash
npm install
npm run tauri dev
```

如开发网络需要代理，请把 `.env.example` 中的变量导出到启动开发的 shell（例如 `export HTTPS_PROXY=http://127.0.0.1:7890`）。注意：直接把 `.env` 文件放在项目根目录不会生效，Vite 不会把它传给 Tauri 的 Rust 进程。不要提交真实代理认证信息。

更新检查仓库通过编译期变量固定：

```bash
export GETTUBE_UPDATE_REPO=owner/gettube
npm run tauri dev
```

仓库未配置或尚无 Release 时，设置页会显示对应状态。当前阶段只运行开发模式、测试和编译检查，不生成安装包。

## 安全边界

仅下载用户有权保存的内容。GetTube 不绕过 DRM，不向远程服务上传 Cookie，并仅允许已知平台的 HTTP/HTTPS 链接进入下载引擎。

粘贴导入的 Netscape Cookie 会以明文托管在本机应用数据目录，Unix 权限为 `0600`，并采用临时文件原子替换。正文不进入设置文件、任务数据库或日志；设置页提供显式清除入口。托管会产生额外凭证副本，删除或卸载不承诺磁盘安全擦除。

抖音解析依赖页面和接口结构，可能随平台风控或 X-Bogus/a_bogus 机制变化而失效。GetTube 只支持普通视频，不支持图集、直播、付费或私密内容；解析失败会明确报错，不会静默下载带水印版本。
